# Warehouse Stage 1

## Compile and Run

Run the command from the `WarehouseStage1` directory to compile and run the test of Warehouse:

```sh
javac *.java && java WarehouseTest > warehouse-test-output.txt
```
The output of the test will be found in warehouse-test-output.txt.
Note that the initial balance of all clients is 0.00 as they have not created a transaction yet.
