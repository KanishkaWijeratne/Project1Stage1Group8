# Warehouse Stage 1

## Compile and Run

Run the command from the `WarehouseStage1` directory to compile and run the test of Warehouse:

```sh
javac *.java && java WarehouseTest\
```
The commands used to run the script interactively were:

```sh
script warehouse-session.txt
javac *.java && java WarehouseTest\
```
The output of the test will be found in warehouse-session.txt. 
Note 1. The initial balance of all clients is 0.00 as they have not created a transaction yet. 2. The output was ran on a CachyOS machine and may contain the logo art within the warehouse-session.txt
